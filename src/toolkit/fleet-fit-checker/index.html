How this verdict is reached
  • Fit is based on vehicle mix, hardware already fitted, who employs the driver, and route connectivity — not on vehicle make or model year.
  • Install window assumes about 10 vehicles per crew-day, with one install crew per 5 depots working in parallel, plus a day for each depot move. Depots cannot exceed vehicles. Placeholder planning figures.
  • Contracted 3PL fleets are workable but need a commercial agreement with the carrier before installation; that step is what moves the verdict to "with notes".
  • Yard plant (forklifts, loaders) uses a different mounting kit and is normally scoped as a separate phase.
  • Poor connectivity does not block deployment: detection runs on the vehicle and events sync when a signal returns. Patchy coverage is noted; remote routes move the verdict to "with notes".
